* nanoshot

Simple screenshotting tool for MacOS.

Build, install and run:
#+begin_src sh
$ cargo build --release
$ ./target/release/nanoshot &
#+end_src

Use:
- Click - Take screenshot
- Ctrl+Click - Take 5 screenshots in a row (5x esc to exit)
